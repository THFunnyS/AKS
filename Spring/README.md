# Spring Boot — Управление покупателями и заказами

## Описание проекта

Веб-приложение для управления покупателями и их заказами. Разработано на Java с использованием Spring Boot и PostgreSQL.

Приложение позволяет просматривать, добавлять, редактировать и удалять записи о покупателях и заказах. Данные сохраняются в базе данных PostgreSQL.

## 1 Используемые технологии

- **Java 17** — язык программирования.
- **Spring Boot** — основа веб-приложения.
- **Spring Web** — обработка HTTP-запросов и маршрутизация.
- **Spring Data JPA** — работа с базой данных.
- **Hibernate** — ORM для взаимодействия с PostgreSQL.
- **Thymeleaf** — формирование HTML-страниц.
- **PostgreSQL** — реляционная база данных.
- **Maven** — управление зависимостями и сборка проекта.

## 2 Структура проекта

Основной код приложения находится в каталоге `aks-spring/src/main/java`, HTML-шаблоны — в `src/main/resources/templates`.

Основные пакеты:

- `Spring.model` — сущности покупателей и заказов.
- `Spring.repository` — репозитории для работы с базой данных.
- `Spring.service` — бизнес-логика и операции с данными.
- `Spring.controller` — обработка запросов пользователя.
- `Spring.dto` — объекты передачи данных между слоями приложения.

Основные HTML-шаблоны:

- `customers.html` — список покупателей.
- `customer-form.html` — форма добавления и редактирования покупателя.
- `orders.html` — список заказов.
- `order-form.html` — форма добавления и редактирования заказа.

## 3 Модель данных

В приложении используются две основные сущности.

### Customer — покупатель

Содержит следующие поля:

- `id` — уникальный идентификатор.
- `name` — имя покупателя.
- `email` — адрес электронной почты.
- `phone` — номер телефона.

### CustomerOrder — заказ

Содержит следующие поля:

- `id` — уникальный идентификатор заказа.
- `orderDate` — дата заказа.
- `totalSum` — сумма заказа.
- `status` — статус заказа.
- `customer` — покупатель, которому принадлежит заказ.

Между сущностями установлена связь **один ко многим**:

```text
Customer 1 ───────── * CustomerOrder
```

## 4 Функциональность

### Работа с покупателями

- Просмотр списка покупателей.
- Добавление нового покупателя.
- Редактирование информации о покупателе.
- Удаление покупателя, у которого нет заказов.
- Проверка корректности вводимых данных и уникальности электронной почты.

Удаление покупателя, у которого есть заказы, запрещено. Перед удалением необходимо удалить связанные заказы.

### Работа с заказами

- Просмотр списка заказов.
- Создание заказа.
- Редактирование заказа.
- Удаление заказа.
- Указание даты, суммы и статуса заказа.
- Выбор покупателя для заказа.

При сохранении заказа проверяется корректность суммы и существование указанного покупателя.

## 5 Требования для запуска

Перед запуском необходимо установить:

- JDK 17 или совместимую версию.
- Maven либо использовать Maven Wrapper, если он присутствует в проекте.
- PostgreSQL.
- IntelliJ IDEA или другую среду разработки (необязательно).

## 6 Настройка базы данных

Приложение использует PostgreSQL.

Параметры подключения указываются в файле `aks-spring/src/main/resources/application.properties`.

Пример конфигурации:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/AKS
spring.datasource.username=postgres
spring.datasource.password=YOUR_PASSWORD

spring.jpa.hibernate.ddl-auto=none
spring.jpa.open-in-view=false
```

Вместо `YOUR_PASSWORD` необходимо указать пароль пользователя PostgreSQL.

Перед запуском приложения необходимо убедиться, что база данных `AKS` существует, а таблицы `customer` и `orders` созданы и содержат необходимые поля и связи.

Параметр `spring.jpa.hibernate.ddl-auto=none` запрещает Hibernate автоматически изменять структуру базы данных. Приложение использует существующую схему.

## 7 Сборка и запуск

1. Откройте проект в IntelliJ IDEA.
2. Убедитесь, что выбран JDK 17.
3. Проверьте настройки подключения к PostgreSQL в `application.properties`.
4. Убедитесь, что база данных доступна.
5. Соберите проект командой:

   ```bash
   mvn clean package
   ```

6. Запустите Spring Boot-приложение из главного класса, помеченного аннотацией `@SpringBootApplication`, либо используйте команду:

   ```bash
   mvn spring-boot:run
   ```

После успешного запуска откройте в браузере:

- Покупатели: `http://localhost:8080/customers`
- Заказы: `http://localhost:8080/orders`

## 8 Обработка ошибок

Приложение отображает сообщения об успешном выполнении операций и об ошибках. Проверки бизнес-логики выполняются в сервисном слое, а контроллеры обрабатывают ошибки и возвращают пользователя к соответствующей странице.
